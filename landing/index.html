FAQ

What counts as an agent loop?

When an AI agent repeats the same action, produces near-identical output, or oscillates between states without making progress.

Does it work with OpenAI / Anthropic / LangChain?

Yes. It wraps any Python function or LLM client. Framework-agnostic.

Will it slow down my agent?

No. Detection adds <1ms per call. It runs in-process, no network latency.

Do I need the cloud version?

No. The open-source SDK works fully offline. Cloud adds dashboards and alerts.

What happens when a loop is detected?

By default, it raises a LoopDetectedError. You can configure it to log, call a webhook, or run a custom callback.

Is it really free?

The core SDK is MIT-licensed, free forever. Cloud monitoring is prepaid, no subscription.
