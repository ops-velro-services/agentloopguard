How It Works

1. Install

pip install agentloopguard-sdk

2. Record

from agentloopguard import LoopGuard

guard = LoopGuard(max_iterations=50)
with guard.session() as session:
    session.record({"tool_name": "search", "tool_args": {}})

3. Handle alerts

Choose raising, logging, or a local callback when a detector finds a configured pattern.

Detection Engines

Exact Repeat

Detects the same tool call repeated consecutively.

Lexical Similarity

Detects consecutive, high-overlap non-empty outputs.

Cost Velocity

Checks recorded cost against a configured rate threshold.

Oscillation

Detects repeated A-B and A-B-C call patterns.

FAQ

What counts as an agent loop?

A repeated tool call, a lexical output repeat, or an oscillating sequence that matches a configured detector.

Does it require a hosted service?

No. The shipped SDK runs locally and has no required runtime dependencies.

What happens when a loop is detected?

By default it raises LoopDetectedError; you can configure logging or a callback.
